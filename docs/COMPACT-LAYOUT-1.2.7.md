# 1.2.7 全站紧凑布局

沿用已有的横向导航、分类配色和小型网络连通行，把适合重复展示的结果统一为桌面双栏；760px 及以下切换单栏。

| 栏目 | 调整 |
| --- | --- |
| 首页出口观测、多站点分流 | 双栏紧凑结果块；名称、状态、完整 IP、请求路径、耗时、复制、评分/Whois/IP 卡片、重试与证据均保留 |
| Claude / GPT / Google | 沿用三张出口与评分结构，统一减少卡片间距；环境字段在宽卡片中双栏；对照表保留横向比较 |
| IP 评分 | 保留评分/属性/安全三块；详情本来已是双栏，减少留白；宽卡片属性采用双栏 |
| 网络连通 | 目标结果改为紧凑双栏，保留采样、重试、停止、来源和证据；目标选择默认折叠 |
| DNS / WebRTC | 保留关键操作和边界说明；DNS 双源对照保留双栏，字段压紧；解析器/ICE 数据保持表格 |
| Cloudflare | 边缘节点结果改为双栏，保留节点/协议；测速、重置、风险查询和验证码不变 |
| 全球 Ping / Whois | 属性字段双栏，探针结果和时间对照继续使用完整表格 |
| 服务状态 | 双栏紧凑卡片，异常说明直接显示，更新时间/事件/组件折叠 |
| IP 卡片 | 保留设计画布、设置和导出操作，统一收紧容器间距 |
| AI 资讯 / 本地帮助 | 资讯条目双栏；帮助正文保留完整宽度阅读 |
| 共用历史记录 | 记录采用紧凑双栏；名称、时间、计数、查看与本次比较完整保留；详细比较表继续全宽 |
| 报告中心 | 分项摘要双栏，点击展开结果与证据；导入、导出、系统合并、模块筛选和历史比较保留 |
| 工具设置 | 表单及数据源说明保留，统一紧凑间距 |

修复脱敏报告回读后“已有脱敏 IP 却标注未取得 IP”的歧义：现在显示“已脱敏 · 需重测”，复制完整 IP 和地址查询链接保持不可用；不能用截断地址伪造可查询的完整 IP。实时完整 IP 即使开启界面隐藏，也仍按实际测量状态显示。

同时补齐历史比较表项目名称中的 IP 隐藏，避免名称含地址时遗漏脱敏。

布局改动不改变检测路径、评分算法、报告数据或系统代理设置。
