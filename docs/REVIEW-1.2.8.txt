Network Desk 1.2.8 源码与 GitHub 公告复查
版本：1.2.8

本次重点：停止与重新检测、报告切换和导入、历史保存、界面脱敏、依赖及公开发布边界。保留 1.2.7 的双列布局和所有栏目。

修复内容
1. 地区核验结束后缺少任务代次检查：停止或切换报告后仍启动连通、DNS、WebRTC 后续阶段。现逐阶段检查，并避免旧任务再次保存新记录。
2. 网络请求只在收到响应头前保留取消控制器：收到头、正文未读完时停止不生效。现将控制器保留到正文解析结束，保留 AbortError 语义；取消后也不启动备用出口请求。
3. 自动历史开关仅存在于一次渲染中，旧异步任务闭包仍可能保存，重启又恢复开启。现读取当前选择并持久保存；关闭后仍可明确点击手动保存。
4. 一条历史记录格式异常导致整个历史列表为空。现逐条验证，其他有效记录仍可使用。
5. 同步抛错发生在任务注册前，已结束的 Promise 可能残留，导致重试没有真正执行。现先注册再执行，并防止旧任务清理同名新任务。
6. 展开的来源、限制说明及出口卡片备用摘要没有统一响应隐藏 IP。现使用同一脱敏显示组件。脱敏并不等于匿名化。

验证方法
停止的两个边界用可控制的响应延迟先复现旧版失败，再检查修复通过；不依赖网络恰好变慢。覆盖重试去重、同步错误、旧结果隔离、历史关闭与重启、损坏记录隔离；保留原报告安全、本机 API 边界、打包依赖及发布检查。
