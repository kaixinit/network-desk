# 使用说明

适用于 1.2.11。完整检测需要本地服务与网络，无需管理员权限，不需要修改 Windows 代理或防火墙。

## 启动与退出

桌面版双击免安装 EXE；网页版完整解压运行包后双击 `启动网络诊断台.cmd`；源码用户先完成 [README](../README.md) 中的安装构建。桌面窗口关闭后服务退出，网页版需关闭服务窗口，关浏览器标签不会停止服务。

## 检测与结果

1. 选择栏目、输入或选择目标，点击检测。部分栏目打开后自动读取数据。
2. 等任务结束，或点击停止保留已有结果。
3. 展开来源/检测详情，核对完整 IP、请求路径、采集时间、错误原因和限制。
4. 需要保留本轮时先导出，再开始新记录或切换记录。

| 状态               | 含义                                               |
| ------------------ | -------------------------------------------------- |
| 已取得 / HTTP 响应 | 取得了对应观测，不自动等于安全、账号可用或注册成功 |
| 无法确定 / 未提供  | 缺少数据或比较依据，展开详情查原因                 |
| 失败 / HTTP 403    | 请求失败或上游拒绝，不等于账号被封或地区一定不支持 |
| 未执行             | 尚未运行，或缺少自有配置                           |
| 已脱敏 · 需重测    | 导入文件无完整 IP，不能复制完整地址或联动查询      |

对比不同站点或浏览器时先核对完整 IP、时间和来源。轮换 IPv6、分流和供应方更新会影响结果，不能仅比较分数。

## 综合排查、结论与交付包（1.2.11）

首页选择本次范围后点击“开始综合排查”。公共出口、设备信息、DNS 和 WebRTC 统一采集；Claude、GPT 和 Google 的连通目标按选择执行。Claude/GPT 的地区核验使用各自完整出口对应的情报，Google 的公网出口仍只是参考。旧记录按当前历史保存开关处理，重要结果请先导出。

桌面版默认勾选只读系统信息合并；取消后不启动脚本。脚本失败不会中断其他检测，报告中保留实际失败原因。网页版可继续用原有脚本和 JSON 导入流程。

“结论摘要”由当前证据生成，HTTP 403/401、限流、请求失败、缺少配置和无法确定分别说明。未取得候选或数据不代表安全，HTTP 200 不保证账号可用。停止或导入未完成记录不会自动继续检测；缺失项目在摘要中明确计数。

交付包导出前固定当前记录快照，后续结果不会混入。预览可查看实际 JSON、是否包含系统信息、导出范围和脱敏开关。点击“确认导出 ZIP”保存：

- `report.html`：离线阅读结论、分项证据和系统信息。
- `report.json`：解压后通过报告中心导入；ZIP 和 HTML 不作为导入格式。
- `使用说明.txt`：交付阅读说明。
- `SHA256SUMS.txt`：前三个文件的完整性校验值，不是数字签名或测量真实性证明。

首页导出包含本次全部数据；报告选项中的交付包遵循所选模块。脱敏文件无法恢复完整 IP；关闭脱敏开关也不能恢复导入时已隐藏的信息。现有 HTML、JSON 单独导出和历史比较保留。

## 单独采集系统信息

1. 完成目标栏目检测。
2. 点击底部“采集系统信息”，读取系统、时区、区域/语言、代理、DNS、IPv6 绑定和网卡摘要。
3. 等待“系统信息已采集并合并”，原始 JSON 保存在默认报告目录。
4. 点击“保存合并报告”选择 HTML 保存位置。
5. 点击右侧箭头“更多报告选项”，可导出 JSON、选模块、调整脱敏或导入文件。

采集期间若切换了记录，JSON 仍保存到报告目录，但不会插入另一记录，可之后手动导入。

## 网页版生成 JSON、导入和导出

双击 `生成系统报告.cmd`，或在项目根目录打开 PowerShell：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\collect-system.ps1
```

输出到项目的 `reports/system-日期-时间.json`。在报告中心或 Google/Gmail 页点击“导入系统 JSON / 报告”，选择文件，无须复制 JSON 文本。

系统 JSON 合并到当前记录；完整 Network Desk 报告则载入那份记录，保留原采集时间和来源。兼容 `google-environment-system/v1` 系统格式。脚本只读，进程级 Bypass 不永久修改策略；若组织策略禁止脚本，遵守本机策略，其他浏览器检测仍可使用。

## 报告、回读与隐私

| 操作          | 用途                                   |
| ------------- | -------------------------------------- |
| 导出 HTML     | 离线阅读，内含同份合并 JSON            |
| 导出 JSON     | 备份数据，之后再次导入软件             |
| 导出范围      | 全部或指定模块，保留相关系统信息与结论 |
| 导出时隐藏 IP | 默认开启，影响文件，不删除本地原始记录 |
| 顶部隐藏 IP   | 只影响界面，与导出选项独立             |

导出后打开实际文件确认。导入入口选择 **JSON**，HTML 用于阅读。格式损坏会拒绝导入并保留当前记录。报告没有数字签名，格式和内部一致性校验不能证明测量来源真实。

脱敏主要处理 IP 和代理地址，不代表匿名：时间、语言、地区、设备与自行填写内容仍可能识别使用者。个人报告、系统 JSON 和截图不属于 GitHub 源码，不应附在公开 Issue 中。

## 历史与迁移

最多自动保留 20 份历史。“自动保留检测历史”立即生效并记住选择；关闭不会删除旧记录，仍可手动保存。支持查看、与本次比较及清除历史。清除历史不删除已导出的文件。

桌面数据位于 `%APPDATA%\NetworkDesk`，不随复制 EXE 迁移。网页存储按浏览器与站点地址隔离，换浏览器或端口可能看不到旧历史。用 JSON 导出/导入迁移。

“在浏览器中复测”打开默认浏览器，需保持 EXE 运行。内嵌 Chromium 不代表 Edge/Chrome 的指纹。本机 HTTP/SOCKS5 设置仅改变本工具服务请求，不改系统或浏览器；详见 [配置说明](CONFIGURATION.md)。

## 常见问题

| 现象                       | 处理                                                          |
| -------------------------- | ------------------------------------------------------------- |
| 源码启动找不到页面         | 先 `npm ci`、`npm run build`；源码包不含前端产物              |
| 双击 HTML 后接口失败       | 用启动脚本或 `npm start`，访问生成的本地地址                  |
| 拒绝跨站请求               | 从软件输出的地址直接访问，不嵌入其他站点、不关闭来源校验      |
| 找不到 curl / PowerShell   | 确认系统命令可用，Node.js 不替代这些运行条件                  |
| 403 / 超时 / CORS          | 展开来源与请求路径，适量重试；上游限制不能保证解除            |
| 验证码未配置               | 可选功能，使用自有配置并自行验证，其他检测仍可用              |
| 配置不生效                 | 核对桌面/网页版路径、JSON 格式，完整退出后重启                |
| 换端口后历史不见           | 网页按来源隔离，用 JSON 迁移；桌面历史不依赖随机端口          |
| Windows 安全或网络权限提示 | 保持现有安全设置；程序不自动添加规则，部分 UDP 观测可能受限制 |

反馈时提供版本、栏目、步骤和错误文字，避免公开个人报告、代理配置或密钥。漏洞报告方式见 [SECURITY.md](../SECURITY.md)。

## 摘要的多轮观测与地区核验

多次切换栏目会保留本次记录中的观测。摘要中的 WebRTC、DNS 各取最新一轮，完整 JSON 仍保存其他轮次；同时涉及多个平台时，范围显示“累计观测”。这不代表所有平台都已完成全项检测。

IPv4 UDP 候选不能与 IPv6 HTTP 出口直接判定相同或不同。此时显示“IPv4 / IPv6 无法直接比较”；可在 WebRTC 栏目点击“自动获取公网 IPv4 并对照”。同协议地址不同也只能说明分流差异，不能单独证明泄露。旧版完整报告导入后会按新规则解释，保留原采集时间和 previousComparison；脱敏数据不能还原完整 IP。

Claude 地区核验读取官方产品帮助页。GPT 官方名单若返回 403，说明这次自动读取被网站拒绝或要求浏览器验证，不等同于 ChatGPT 不通或账号被封。无需 API 密钥；在对应栏目展开支持地区，点击“在浏览器查看官方名单”人工核对，或“重新核验地区”重试。软件不会自动通过网站验证，也不会把失败改成通过。

## 1.2.11：复测与官方名单参考

连通探测首次 HEAD 传输失败时，同一路径最多增加一次 GET 复核；成功后仍保留“首次失败，复测恢复”的提醒。两次均失败则展示失败阶段及只读 DNS 证据。解析到 198.18/15 可能来自代理映射，本身不表示泄露或网络损坏；结合 TCP 是否建立及代理接管规则判断。软件不会自动切换系统代理、修改 TUN 或分流规则。

GPT 实时名单抓取可能被网站的验证页面拒绝。随附的 ChatGPT 官方地区名单参考核对于 2026-11-02，有效期 30 天，来源和日期在界面及报告中保留。实时读取失败时 applicable 仍为空、状态为“无法确定”；参考只回答核对日期时名单是否列出此地区，不保证当前支持，更不表示账号可用。到期不再采用参考成员关系。需要时可展开摘要直接重新核验，或人工查看官方页面。

## 1.2.12：握手阶段与代理分流

curl 的连接超时包含 DNS、TCP、代理协商和 TLS；失败时 time_connect 为零不能单独证明 TCP 未建立。软件结合 CONNECT 状态及握手事件显示失败阶段。隧道返回 200 不等于目标 HTTPS 可用；缺少阶段证据时明确标注无法细分。原始认证头、Cookie 和证书正文不进入报告。

代理处于全局模式时，国内网站也可能经所选海外节点。若同一网址的直连探测正常、当前节点路径失败，可先考虑规则模式及精确域名直连规则；应评估其他流量的路由影响后由用户确认。本软件不会代为切换模式、节点、TUN 或系统代理。

GPT 帮助页的浏览器验证可能返回 403 或 200，均不能充当有效名单。可从摘要直接打开官方名单核对；客户端验证和官方名单参考均不证明账号状态。
