# 配置说明

基础 IP、设备、连通、DNS/WebRTC 和报告功能不要求密钥。可选功能会如实显示未配置、限流或无法确定。

## 文件与字段

| 方式            | 位置                                                              |
| --------------- | ----------------------------------------------------------------- |
| EXE             | `%APPDATA%\NetworkDesk\config.local.json`，工具设置页显示实际路径 |
| 本地网页 / 源码 | 启动脚本所在项目根目录的 `config.local.json`                      |

以 `config.example.json` 为模板创建文件；已有文件只补充字段，不覆盖现有配置。使用合法 JSON，未配置项留空。保存后完整退出并重启。不要把本地文件复制进准备提交的源码目录。

| 字段                                                               | 用途                                         |
| ------------------------------------------------------------------ | -------------------------------------------- |
| `ipapiKey`                                                         | 可选 ipapi.is 情报，权限和额度由供应方决定   |
| `globalpingToken`                                                  | 可选 Globalping 认证，无令牌可能使用匿名额度 |
| `turnstileSiteKey` / `turnstileSecret`                             | 自有 Turnstile Managed 部件                  |
| `turnstileNoninteractiveSiteKey` / `turnstileNoninteractiveSecret` | 自有 Turnstile Non-interactive 部件          |
| `recaptchaSiteKey` / `recaptchaSecret`                             | 自有 reCAPTCHA v3、兼容 siteverify 的配置    |

Secret 仅由本机后端读取；公开配置接口返回公钥和配置状态，公钥用于浏览器加载部件。主机名和部件类型应与实际入口匹配，不借用其他网站的密钥，不用固定通过的测试密钥冒充实际结果。验证码通过只代表自己的集成。

## 应用内请求方式

在工具设置或对应栏目中选择：

| 选项                     | 行为                                                        |
| ------------------------ | ----------------------------------------------------------- |
| curl 默认路径 / 环境变量 | 不额外指定代理，遵循 curl 环境，不保证读取 Windows 系统代理 |
| curl 显式不设 HTTP 代理  | 使用 no-proxy 选项，仍受系统路由、TUN 和网络设备影响        |
| 本机 HTTP 代理端口       | 使用 `127.0.0.1` 上已有 HTTP / mixed 服务                   |
| 本机 SOCKS5 代理端口     | 使用 SOCKS5h，由代理解析域名                                |

只作用于本机服务请求。浏览器 fetch、WebRTC 和远端探针路径不同。允许端口范围为 1024–65535；默认 `7890` 是示例，不表示发现了监听服务；HTTP 端口也不一定支持 SOCKS5。此入口不接受代理用户名或密码。

这些选择只存在于本应用数据或浏览器站点存储，不改 Windows 代理、TUN 或网卡。不把个人代理订阅、PAC 地址、节点或控制面板密钥放进源码。

## 开发与打包变量

普通使用无需设置：

| 变量                     | 用途                                                               |
| ------------------------ | ------------------------------------------------------------------ |
| `NETWORK_DESK_NODE_DIR`  | 打包时指定官方 Windows x64 Node 目录，需有 `node.exe` 和 `LICENSE` |
| `NETWORK_DESK_URL`       | 实时测试连接地址，默认 `http://127.0.0.1:8780`                     |
| `NETWORK_DESK_DATA_DIR`  | 后端读取配置的目录覆盖，桌面主进程会设置                           |
| `NETWORK_DESK_USER_DATA` | 桌面开发测试覆盖用户数据目录，普通使用 AppData                     |

仅在当前终端按需设置，不要提交含个人绝对路径的 `.env`、脚本或日志。这些变量不会设置 Windows 系统代理。
